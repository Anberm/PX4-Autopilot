# PX4 多专家协作记忆系统

## 概述
本目录用于存储多专家协作过程中的共享记忆，包括任务记录、决策记录和项目上下文。

## 目录结构

```
memory/
├── tasks/          # 任务记录
├── decisions/      # 决策记录 (ADR)
├── context/        # 项目上下文
│   └── project-overview.md
└── README.md       # 本文件
```

## 使用规范

### 任务记录 (tasks/)
用于记录进行中和已完成的任务。

**文件命名**: `YYYYMMDD-任务名称.md`

**格式**:
```markdown
# 任务名称

## 基本信息
- **创建时间**: YYYY-MM-DD
- **状态**: 进行中/已完成/阻塞
- **负责专家**: [专家名称]

## 任务描述
[详细描述]

## 进展记录
- [日期] [进展内容]

## 产出物
- [文件列表]

## 遗留问题
- [问题列表]
```

### 决策记录 (decisions/)
用于记录重要的架构和技术决策 (ADR - Architecture Decision Records)。

**文件命名**: `ADR-XXXX-决策标题.md`

**格式**:
```markdown
# ADR-XXXX: 决策标题

## 状态
已接受 / 已废弃 / 已取代

## 上下文
[描述做出此决策的背景和原因]

## 决策
[描述做出的决策]

## 后果
[描述决策的影响，包括正面和负面]

## 备选方案
[考虑过的其他方案]
```

### 项目上下文 (context/)
存储项目的基本信息和当前状态。

- `project-overview.md` - 项目概述
- 可根据需要添加更多上下文文件

## 记忆管理职责

### Coordinator
- 维护任务状态
- 协调记忆更新
- 解决记忆冲突

### Project Manager
- 维护任务记录
- 协助记录决策
- 定期清理过期记忆

### 各专家
- 记录技术决策
- 更新相关上下文
- 完成任务后更新记忆

## 最佳实践

1. **及时更新**: 任务完成后立即更新记忆
2. **清晰记录**: 使用标准格式，便于其他专家理解
3. **关联引用**: 相关记忆之间建立引用
4. **定期清理**: 清理过期和无关的记忆
5. **版本控制**: 重要决策记录变更历史
