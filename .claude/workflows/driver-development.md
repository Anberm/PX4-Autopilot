# 驱动开发工作流

## 概述
本工作流定义了 PX4 传感器驱动或新飞控板适配的开发流程。

## 流程图
```
[需求分析] → [驱动设计] → [驱动实现] → [模块集成] → [测试验证] → [合并发布]
    PM         DRV          DRV          PX4         TEST         PM
```

## 详细步骤

### 阶段 1: 需求分析 (Project Manager)
**输入**: 硬件需求
**输出**: 任务分解

1. 获取硬件数据手册
2. 分析通信接口 (SPI/I2C/UART)
3. 确定数据格式和采样率
4. 识别相关 uORB 消息
5. 创建 Issue 跟踪

**交付物**:
- [ ] 数据手册获取
- [ ] 接口分析
- [ ] Issue 创建

### 阶段 2: 驱动设计 (Driver Expert)
**输入**: 任务分解
**输出**: 驱动设计

1. 分析硬件寄存器和协议
2. 设计驱动类结构
3. 确定采样策略
4. 规划校准流程
5. 设计参数配置

**交付物**:
- [ ] 驱动架构设计
- [ ] 寄存器映射
- [ ] 参数设计

### 阶段 3: 驱动实现 (Driver Expert)
**输入**: 驱动设计
**输出**: 驱动代码

1. 创建驱动目录结构
```
src/drivers/[type]/[chip]/
├── CMakeLists.txt
├── Kconfig
├── [chip].cpp
├── [chip].hpp
└── [chip]_registers.hpp
```

2. 实现驱动类
   - 继承 I2CSPIDriver
   - 实现 init/probe/RunImpl
   - 发布 uORB 消息

3. 添加构建配置
   - CMakeLists.txt
   - Kconfig 选项

4. 本地编译测试

**交付物**:
- [ ] 驱动代码
- [ ] 构建配置
- [ ] 编译通过

### 阶段 4: 模块集成 (PX4 Firmware Expert)
**输入**: 驱动代码
**输出**: 集成代码

1. 在 Sensors 模块中集成
2. 配置启动脚本
3. 添加校准支持
4. 更新板级配置 (如需要)

**交付物**:
- [ ] Sensors 集成
- [ ] 启动脚本
- [ ] 板级配置

### 阶段 5: 测试验证 (Test Expert)
**输入**: 集成代码
**输出**: 测试报告

1. 硬件连接测试
2. 数据读取验证
3. 采样率验证
4. 性能测试
5. 长时间稳定性测试

**交付物**:
- [ ] 硬件测试通过
- [ ] 性能验证
- [ ] 稳定性测试

### 阶段 6: 合并发布 (Project Manager)
**输入**: 测试通过
**输出**: 代码合并

1. 创建 Pull Request
2. 代码审查
3. CI 测试通过
4. 合并代码
5. 更新文档

**交付物**:
- [ ] PR 合并
- [ ] 文档更新

## 新飞控板适配流程

### 板级目录结构
```
boards/[manufacturer]/[board]/
├── default.px4board          # 默认构建配置
├── bootloader.px4board       # Bootloader 配置
├── firmware.prototype        # 固件原型定义
├── init/
│   ├── rc.board_defaults     # 默认参数
│   └── rc.board_sensors      # 传感器启动
├── nuttx-config/
│   ├── include/
│   │   ├── board.h           # 板级定义
│   │   └── board_dma_map.h   # DMA 映射
│   ├── nsh/defconfig         # NuttX 配置
│   └── scripts/script.ld     # 链接脚本
└── src/
    ├── board_config.h        # 板级配置头文件
    ├── init.c                # 初始化代码
    ├── spi.cpp               # SPI 配置
    ├── i2c.cpp               # I2C 配置
    └── timer_config.cpp      # 定时器配置
```

### 适配步骤
1. 复制相似板级作为模板
2. 修改 board_config.h (引脚定义)
3. 配置 NuttX defconfig
4. 配置 SPI/I2C 总线
5. 配置 PWM 输出
6. 配置传感器启动脚本
7. 构建和测试

## 协作矩阵

| 阶段 | PM | DRV | PX4 | TEST |
|-----|:--:|:---:|:---:|:----:|
| 需求分析 | ★ | ○ | - | - |
| 驱动设计 | - | ★ | - | - |
| 驱动实现 | - | ★ | - | - |
| 模块集成 | - | ○ | ★ | - |
| 测试验证 | - | ○ | ○ | ★ |
| 合并发布 | ★ | - | - | - |

★ = 主要负责, ○ = 辅助参与, - = 不参与

## 质量门禁

1. **需求分析 → 驱动设计**
   - 数据手册已获取
   - 接口已确定

2. **驱动设计 → 驱动实现**
   - 架构设计完成
   - 寄存器映射完成

3. **驱动实现 → 模块集成**
   - 驱动编译通过
   - 基本功能实现

4. **模块集成 → 测试验证**
   - 集成编译通过
   - 启动脚本配置

5. **测试验证 → 合并发布**
   - 硬件测试通过
   - 性能满足要求
