# 算法优化工作流

## 概述
本工作流定义了 PX4 飞控算法（EKF、控制器等）优化的标准流程。

## 流程图
```
[问题分析] → [算法设计] → [算法实现] → [仿真验证] → [实飞验证] → [合并发布]
   COORD        FC           FC          TEST        TEST         PM
```

## 详细步骤

### 阶段 1: 问题分析 (Coordinator)
**输入**: 性能问题描述
**输出**: 问题分析报告

1. 收集性能问题描述
2. 获取 Flight Review 日志
3. 分析性能指标
4. 确定优化目标
5. 分配给飞控算法专家

**常见优化场景**:
| 问题类型 | 关注指标 |
|---------|---------|
| EKF 漂移 | 创新值、协方差 |
| 姿态振荡 | 姿态误差、角速率 |
| 位置跟踪差 | 位置误差、速度误差 |
| 控制延迟 | 设定点到响应时间 |

**交付物**:
- [ ] Flight Review 分析
- [ ] 性能指标识别
- [ ] 优化目标定义

### 阶段 2: 算法设计 (Flight Control Expert)
**输入**: 问题分析报告
**输出**: 优化方案

1. 分析现有算法实现
2. 研究相关文献
3. 设计优化方案
4. 评估计算开销
5. 设计参数调整

**重点关注**:
- 算法稳定性
- 计算效率
- 参数可调性
- 向后兼容

**交付物**:
- [ ] 算法分析
- [ ] 优化方案设计
- [ ] 参数设计

### 阶段 3: 算法实现 (Flight Control Expert)
**输入**: 优化方案
**输出**: 优化代码

1. 创建开发分支
2. 实现算法优化
3. 添加/调整参数
4. 添加调试日志
5. 代码自检

**代码规范**:
```cpp
// 添加详细注释说明算法原理
// 使用参数控制新功能
DEFINE_PARAMETERS(
    (ParamFloat<px4::params::EKF2_NEW_PARAM>) _param_new_feature
)

// 添加日志输出
PX4_DEBUG("Innovation: %.4f", (double)innovation);
```

**交付物**:
- [ ] 优化代码
- [ ] 参数定义
- [ ] 调试日志

### 阶段 4: 仿真验证 (Test Expert)
**输入**: 优化代码
**输出**: 仿真测试报告

1. 配置 SITL 仿真环境
2. 设计测试场景
3. 运行仿真测试
4. 分析性能指标
5. 对比优化前后

**测试场景**:
```bash
# 基本悬停测试
make px4_sitl gazebo-classic_iris

# 轨迹跟踪测试
# 使用 MAVSDK 执行预定义轨迹

# 扰动测试
# 模拟风扰、传感器噪声
```

**交付物**:
- [ ] SITL 测试通过
- [ ] 性能对比分析
- [ ] Flight Review 报告

### 阶段 5: 实飞验证 (Test Expert)
**输入**: 仿真验证通过
**输出**: 实飞测试报告

1. 准备测试飞行器
2. 配置参数
3. 执行测试飞行
4. 收集日志数据
5. 分析实飞性能

**实飞测试检查点**:
- [ ] 安全措施就绪
- [ ] 基本功能正常
- [ ] 性能指标达标
- [ ] 无异常振动
- [ ] 故障模式测试

**交付物**:
- [ ] 实飞测试通过
- [ ] 性能验证报告
- [ ] Flight Review 链接

### 阶段 6: 合并发布 (Project Manager)
**输入**: 验证通过
**输出**: 代码合并

1. 创建 Pull Request
2. 详细描述优化内容
3. 提供性能对比数据
4. 代码审查
5. 合并代码
6. 更新文档

**交付物**:
- [ ] PR 合并
- [ ] 参数文档更新
- [ ] 调参指南更新

## 协作矩阵

| 阶段 | COORD | FC | TEST | PM |
|-----|:-----:|:--:|:----:|:--:|
| 问题分析 | ★ | ○ | - | - |
| 算法设计 | - | ★ | - | - |
| 算法实现 | - | ★ | - | - |
| 仿真验证 | - | ○ | ★ | - |
| 实飞验证 | - | ○ | ★ | - |
| 合并发布 | - | - | - | ★ |

★ = 主要负责, ○ = 辅助参与, - = 不参与

## 性能指标

### EKF 性能指标
- 创新值 (Innovation) < 阈值
- 协方差收敛
- 位置/速度误差

### 控制器性能指标
- 稳态误差
- 超调量
- 调节时间
- 相位裕度

## 参数调优指南

### EKF2 关键参数
```
EKF2_GPS_V_NOISE  # GPS 速度噪声
EKF2_GPS_P_NOISE  # GPS 位置噪声
EKF2_ACC_NOISE    # 加速度计噪声
EKF2_GYR_NOISE    # 陀螺仪噪声
```

### 控制器关键参数
```
# 多旋翼位置控制
MPC_XY_P          # 位置 P 增益
MPC_XY_VEL_P_ACC  # 速度 P 增益
MPC_Z_P           # 高度 P 增益

# 多旋翼姿态控制
MC_ROLL_P         # 横滚 P 增益
MC_PITCH_P        # 俯仰 P 增益
MC_YAW_P          # 偏航 P 增益
```

## 质量门禁

1. **问题分析 → 算法设计**
   - 问题已清晰定义
   - 性能指标已确定

2. **算法设计 → 算法实现**
   - 方案已评审
   - 计算开销可接受

3. **算法实现 → 仿真验证**
   - 代码编译通过
   - 单元测试通过

4. **仿真验证 → 实飞验证**
   - SITL 测试通过
   - 性能指标达标

5. **实飞验证 → 合并发布**
   - 实飞验证通过
   - 无安全隐患
